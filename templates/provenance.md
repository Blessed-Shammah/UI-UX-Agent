# Resource provenance

Use one entry for each adopted external code or asset source. References used only for inspiration should also be identified, with no claim of licensed reuse.

| Field | Record |
| --- | --- |
| Resource and author | Actual source identity |
| Source URL | Official repository or author page |
| Revision | Exact commit/tag or asset version |
| Reviewed | Date and who inspected it |
| Use | Code adoption, image, font, icon, or inspiration only |
| License | License identifier and source license-file URL/path |
| Separate assets | Font/image/plugin licenses and unresolved rights |
| Notices | Where required attribution/license notices are retained |
| Changes | Product-specific modifications |
| Verification | Build, render, interaction checks; remaining limitations |
