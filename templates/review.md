# Interface review

**Verdict:** Keep / Refine / Rethink / Insufficient evidence.

State the reviewed artifact, task, and evidence in one sentence. Select a verdict only after inspection; this template itself is not a completed assessment.

**Keep:** Name one or two specific strengths and why they help the user.

**Improve:** Give zero to three priorities. For each, use:

- **Location:** Observed issue → user consequence → smallest suitable correction → how to verify.

If appropriate, write “No material changes recommended within the reviewed scope.” Disclose any additional critical blockers even if there are more than three. Separate optional taste preferences from defects.

**Better approach:** Include only for a justified structural change. Describe the better flow/composition, first implementation step, what remains intact, and tradeoff. Prefer a small repair where it solves the problem.

**Unverified:** List only material missing evidence or checks. Omit if there are none.

Keep an ordinary review around 150–250 words or shorter when the work is sound. Do not edit the implementation unless the user requested corrections.
